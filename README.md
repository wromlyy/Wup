# Wup

Wup — самостоятельный WhatsApp-style интерфейс для Android WebView или браузера. В проекте есть список чатов, экран переписки, поиск, фильтры, отправка локальных демо-сообщений и настройки оформления.

## Кастомизация

- Liquid Glass панели с регулируемой прозрачностью;
- светлая и тёмная тема;
- шесть готовых акцентных цветов и собственный HEX-цвет;
- настройка радиуса карточек;
- компактная, удобная и свободная плотность списка чатов;
- настройки сохраняются в `localStorage`.

## Запуск

Открой `index.html` в браузере. Для проверки JavaScript:

```sh
npm run check
```

Это UI-основа. Подключение аккаунта, синхронизация сообщений и звонки требуют отдельного сервера и разрешённого API; проект не подменяет официальный WhatsApp и не обходит его защиту.
